# Scarica Compendio del Party

Scegli il tuo computer. Il download è gratuito e si apre senza account GitHub.

| Computer | Download | Come aprirlo |
| --- | --- | --- |
| Mac | [Scarica per Mac](https://github.com/nicogatti/akaoni-compendium-updates/releases/download/party-v0.4.0/Compendio-del-Party-Mac.dmg) | Apri il file, trascina **Compendio del Party** in **Applicazioni** e aprilo da lì. |
| Windows | [Scarica per Windows](https://github.com/nicogatti/akaoni-compendium-updates/releases/download/party-v0.4.0/Compendio-del-Party-Windows.exe) | Apri il file e segui le istruzioni. Troverai il Party nel menu Start. |
| Linux | [Scarica per Linux](https://github.com/nicogatti/akaoni-compendium-updates/releases/download/party-v0.4.0/Compendio-del-Party-Linux.AppImage) | Salva il file, apri le sue proprietà, abilita l’esecuzione e fai doppio clic. |

## Giocare

Apri **I tuoi personaggi**. Scegli una scheda salvata, **Crea personaggio** per iniziare al livello 1 oppure **Ho già un PG** per inserire la scheda che usi al tavolo.

## Aggiornare

Dalla versione 0.4.0 premi **Controlla aggiornamenti** nella schermata **I tuoi personaggi**. Se usi una versione precedente, installa una volta il file per il tuo computer.

## Per il Master

Il giocatore apre la sua scheda trascritta, preme **Esporta JSON** e ti invia il file. Apri **Ho già un PG → Backup → Importa JSON** e scegli il file ricevuto. Avrai sul tuo computer una copia della scheda al momento dell’esportazione.
